Alien PLC I/O ยังไม่เชื่อมต่อ

RUN/STOP: -

อินพุต X ไฟเขียว = มีสัญญาณ

รีเลย์เอาต์พุต กดเพื่อเปิด/ปิด · คอมมอน: C0 = Y0–Y1, C1 = Y2–Y3, C2 = Y4–Y7

หัวพินขยาย GND · PWM · A1 · A0 · 3V

PWM (PA6) 0 / 255 (0%)

อนาล็อก: แตะหรือต่อแรงดันเข้า A0 / A1 แล้วดูว่าช่องไหนค่าเปลี่ยน (กรอบส้ม) แล้วเลือกชื่อให้ช่องนั้น

ค่าที่แสดงคือแรงดันที่ ขาชิป (0–3.3V) ถ้าบอร์ดมีวงจรแบ่งแรงดันสำหรับ 0–10V ค่าที่ขั้วจริงจะสูงกว่านี้ตามอัตราส่วน

ไฟสถานะบนบอร์ด

ขาอื่น ๆ ที่ยังไม่รู้หน้าที่ กรอบส้ม = เพิ่งเปลี่ยน · ตัวเลข = จำนวนครั้งที่เปลี่ยน

Log ข้อความล่าสุดจากบอร์ด
